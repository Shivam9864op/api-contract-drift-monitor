# Contributing

Thanks for taking a look. This project is intentionally small and deterministic.

## Before opening a change

- Keep examples synthetic and free of credentials or private data.
- Add a focused test for each new comparison rule.
- Keep CLI output readable for both humans and CI logs.
- Run `npm test` locally.

## Pull requests

Please describe the contract change the tool should detect, the expected severity, and one before/after fixture. Avoid changing unrelated formatting or introducing network calls.
